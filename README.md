# Jocha Compare Price

Jocha Compare Price เป็นเว็บแอพสำหรับเปรียบเทียบความคุ้มค่าของสินค้า 2 หรือ 3 ชิ้น โดยคำนวณจาก
- ราคา (บาท)
- ส่วนลดคูปองของแต่ละสินค้า (เปอร์เซ็นต์หรือจำนวนบาท)
- ปริมาตรต่อชิ้น
- ตัวคูณขนาดเทียบปกติ เช่น ทิชชู่ความยาวปกติ `1.0` เท่า และแบบยาว `1.5`, `2` หรือ `3` เท่า
- โหมดสินค้า: ชิ้นเดียว หรือแบบแพ็ก (ระบุจำนวนชิ้นในแพ็ก)

หากต้องการเทียบสินค้า 3 ชิ้น ให้เลือก `3 สินค้า` ที่แถบด้านขวาบน

ฟีเจอร์เพิ่ม:
- สลับภาษาไทย/อังกฤษได้ทันที
- บันทึกประวัติการคำนวณใน browser (localStorage)
- ล้างประวัติได้จากหน้าแอพ
- แสดงกราฟอันดับต้นทุนต่อหน่วยหลังคำนวณ
- คัดลอกลิงก์ผลลัพธ์เพื่อเปิดข้อมูลและผลเปรียบเทียบเดิมบนอุปกรณ์อื่น

ผลลัพธ์จะแสดงว่า
- ต้นทุนต่อหน่วย (บาทต่อหน่วยปริมาตร)
- อันดับความคุ้มค่าเมื่อเปรียบเทียบ 3 ชิ้น
- ชิ้นไหนคุ้มค่ากว่าและคุ้มกว่ากี่เปอร์เซ็นต์เมื่อเปรียบเทียบ 2 ชิ้น

## วิธีใช้งาน

1. ใส่หน่วยปริมาตร เช่น `ml`, `g`, `L`
2. กรอกข้อมูลสินค้า A และสินค้า B
3. เลือกโหมดสินค้า
   - `ชิ้นเดียว` = จำนวนชิ้นในแพ็กเป็น 1 อัตโนมัติ
   - `แบบแพ็ก` = ระบุจำนวนชิ้นในแพ็ก
4. หากมีคูปอง ให้ติ๊ก `ใช้ส่วนลดคูปอง` แล้วกรอกส่วนลดเป็นเปอร์เซ็นต์หรือจำนวนบาท
5. หากสินค้ามีความยาวต่างจากปกติ ให้ติ๊ก `กำหนดความยาวเทียบปกติ` แล้วกรอกตัวคูณ (เช่น `1.5`); สินค้าทั่วไปไม่ต้องติ๊ก
6. กดปุ่ม `คำนวณความคุ้มค่า`
7. กด `คัดลอกลิงก์ผลลัพธ์` ใต้กราฟเมื่อต้องการแชร์ผลเปรียบเทียบ

## สูตรที่ใช้

- ปริมาณเทียบมาตรฐานรวม = ปริมาตรต่อชิ้น × จำนวนชิ้น × ตัวคูณขนาด
- ราคาหลังคูปอง = ราคา - ส่วนลดคูปอง (ส่วนลดไม่เกินราคา)
- ต้นทุนต่อหน่วย = ราคาหลังคูปอง ÷ ปริมาตรรวม
- เปอร์เซ็นต์ความคุ้มค่าที่ดีกว่า =

`((ต้นทุนต่อหน่วยของตัวที่แพงกว่า - ต้นทุนต่อหน่วยของตัวที่ถูกกว่า) ÷ ต้นทุนต่อหน่วยของตัวที่แพงกว่า) × 100`

## โครงสร้างไฟล์

- `index.html` หน้าเว็บ
- `styles.css` สไตล์
- `app.js` ตรรกะคำนวณ
- `DEPLOY.md` วิธี deploy ขึ้น GitHub Pages
- `PUBLISH.ps1` คำสั่งช่วย push ขึ้น GitHub

## Push ขึ้น GitHub แบบเร็ว

1. สร้าง repo บน GitHub ชื่อ `jocha-compare-price`
2. เปิด PowerShell ในโฟลเดอร์โปรเจกต์
3. รันคำสั่ง:

```powershell
.\PUBLISH.ps1 -GitHubUser <your-github-username> -RepoName jocha-compare-price
```
